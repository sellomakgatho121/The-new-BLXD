# Blacklight Web Designs

A clean Next.js App Router + TypeScript starting point. This scaffold is a deliberate new-stack choice; it does not import application code from either source repository.

## Development

- Node.js 20.9 or newer
- `npm ci`
- `npm run dev`

## Verification

`npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.

This baseline contains no authentication, persistence, contact submission, deployment configuration, or production credentials. Those integrations require separate approved contracts and provider decisions.
